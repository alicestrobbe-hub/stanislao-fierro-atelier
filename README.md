# Stanislao Fierro — Architettura

Portfolio Next.js con fotografie, schizzi e schede dei progetti. Gli asset sono inclusi in `public/`.

## Sviluppo locale

Con Node.js 24:

```sh
npm ci
npm run dev
```

## Vercel

Importa il repository come progetto Next.js. Usa la root del repository e il comando di build predefinito `npm run build`. Il sito non richiede variabili d’ambiente.
